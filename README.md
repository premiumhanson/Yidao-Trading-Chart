# Yidao Trading Chart

双击 [启动看盘.cmd](启动看盘.cmd) 后会打开本机浏览器。程序使用已安装的 Node.js 24.15+，图表库随项目提供。窗口显示的本机地址默认为 `http://127.0.0.1:17651/`，关闭命令窗口即可停止。

本地回放接受兼容的 `market_1h.sqlite`。将数据库放在项目的 `resources` 文件夹，或复制 `.env.example` 为 `.env.local` 并用 `KUNHOU_DB` 指定路径。数据库以只读模式打开。同一个浏览器与端口会保留收藏、画线、指标开关和模拟复盘记录。

## 看盘和回放

- 默认左列 4H / 1H，右列 15 分钟 / 周线。点击图表后可用顶部按钮更改该图周期，也可用各图的周期下拉框调整。点击「联动」可切为单图。
- 本地 H1 库只支持小时及以上粒度。15 分钟窗在接入 cTrader 后加载真正的 M15 历史 K 线。
- 右侧支持按代码或中文名称搜索和收藏。用左侧工具添加趋势线、水平线或 20 周期均线。拖动图表或滚动鼠标可以浏览；靠近已加载历史的左端会继续拉取。
- 右上角可分别开关顶底识别、枢纽点和磁力线。指标的已确认公式、默认设置和近似范围见 [指标拆解](指标拆解.md)。
- 点击「回放」可指定日期、选随机起点、前后逐根浏览或自动播放。可用的图表共用一个 H1 游标。高周期 K 线只用游标截至的小时数据计算。模拟复盘可以按 +3R 和 −1R 记录结果、撤销和查看统计。
- 本地高周期使用 UTC 整点、日界、周一和自然月分桶，界面显示 UTC+8。原版的精确交易日、夏令时和跨缺口分桶规则未能确认，因此某些高周期 K 线可能和原版不同。

## cTrader 行情

按 [cTrader 接入说明](cTrader接入.md) 在 `.env.local` 配置已授权的 Open API 应用和账户，重启后从右上角选择 cTrader。选中的品种会接收实时 Bid/Ask 和已收盘 K 线推送，历史 K 线定期补齐。覆盖的品种和历史长度取决于券商。

The Trading Pit 的挑战账号使用 Demo 环境。授权页列出该账号后，即可用它测试只读行情。回放使用本地 H1 库。

## 验证

运行 `node --disable-warning=ExperimentalWarning --test tests/*.test.mjs` 可执行本地聚合、指标和 cTrader 协议模拟测试。服务使用 Node.js 内置模块，图表库随项目提供。

图表使用 TradingView Lightweight Charts™ v5.3.0，许可及归属说明随 `public/vendor` 附带。 [项目文档](https://tradingview.github.io/lightweight-charts/docs)
