# Yidao Trading Chart

双击 [启动看盘.cmd](启动看盘.cmd) 后会打开本机浏览器。程序使用已安装的 Node.js 24.15+，图表库随项目提供。窗口显示的本机地址默认为 `http://127.0.0.1:17651/`，关闭命令窗口即可停止。

本地回放接受兼容的 `market_1h.sqlite`。将数据库放在项目的 `resources` 文件夹，或复制 `.env.example` 为 `.env.local` 并用 `KUNHOU_DB` 指定路径。数据库以只读模式打开。同一个浏览器与端口会保留收藏、画线、指标开关和模拟复盘记录。

## 看盘和回放

- 默认左上 1H、左下 4H、右上 15 分钟、右下周线。点击图表后可用顶部按钮更改该图周期，也可用各图的周期下拉框调整。点击「联动」可切为单图。
- 启动时优先连接「cTrader 本地」，桥接暂不可用时打开本地历史库。跟随最新 K 线时，图表右侧至少留出图表宽度的 1/6。拖动浏览历史后，点击图头的「回到最新」恢复跟随。
- 本地 H1 库只支持小时及以上粒度。15 分钟窗在接入 cTrader 后加载真正的 M15 历史 K 线。
- 右侧支持按代码或中文名称搜索和收藏。用左侧工具添加趋势线、水平线或 20 周期均线。拖动图表或滚动鼠标可以浏览；靠近已加载历史的左端会继续拉取。
- 右上角可分别开关顶底识别、枢纽点和磁力线。指标的已确认公式、默认设置和近似范围见 [指标拆解](指标拆解.md)。
- 点击「回放」可指定日期、选随机起点、前后逐根浏览或自动播放。可用的图表共用一个 H1 游标。高周期 K 线只用游标截至的小时数据计算。模拟复盘可以按 +3R 和 −1R 记录结果、撤销和查看统计。
- 本地高周期使用 UTC 整点、日界、周一和自然月分桶，界面显示 UTC+8。原版的精确交易日、夏令时和跨缺口分桶规则未能确认，因此某些高周期 K 线可能和原版不同。

## cTrader 行情

选择「cTrader 本地」可以通过已登录的桌面终端读取历史和实时行情。按 [本地桥接说明](cTrader本地桥.md) 在 cTrader Algo 本地启动只读 cBot。终端提供 Bid/Ask、正在形成的 K 线及收盘 K 线。

浏览原库同名品种时，Yidao 会用 cTrader 提供的已收盘 H1 从原库末尾续接。右侧也可点击「补历史」。续接数据写入项目内的 `data/ctrader-h1.sqlite`，本地看盘和回放一起读取。

「cTrader Open API」使用 [Open API 凭证](cTrader接入.md) 接入。两种 cTrader 数据源的品种和历史长度由券商提供。回放使用本地 H1 库。

## 本机警报

在顶部「警报」面板添加当前品种。Yidao 服务在后台读取 cTrader 本地桥的 1H 和 4H 收盘 K 线，独立于浏览器显示的品种或周期。1H 信号继续使用同方向的已确认 4H 区域作过滤。

首次监测时会记录最近 7 天的已确认信号，标为「历史回填」。继续监测后出现的迟到信号标为「补记」。同品种、同周期、同方向的一根 K 线只留一条，可查看 P5、P10、P15 结果。警报默认按品种合并，卡片显示最新警报、1H 和 4H 最近信号、近 7 天的方向计数。展开卡片可分页查看该品种历史，也可以切换为逐条显示。

监测清单与历史保存在 `data/alerts.sqlite`，重开页面或重启 Yidao 后可继续查看。实时警报在看盘页显示提示，后台监测依赖 Yidao 服务和 cTrader 本地桥保持运行。

## 验证

运行 `node --disable-warning=ExperimentalWarning --test tests/*.test.mjs` 可执行本地聚合、指标和 cTrader 协议模拟测试。图表库和 WebSocket 库随项目提供。

图表使用 TradingView Lightweight Charts™ v5.3.0，许可及归属说明随 `public/vendor` 附带。 [项目文档](https://tradingview.github.io/lightweight-charts/docs)
